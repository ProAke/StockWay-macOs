# StockWay — จัดเก็บของในบ้าน

เว็บแอปภาษาไทยสำหรับบันทึกสิ่งของพร้อมรูป ค้นหาตำแหน่งจัดเก็บ และติดตามวันหมดอายุ รองรับการใช้งานทั้งบนมือถือและเดสก์ท็อป

## เริ่มใช้งาน

```sh
npm ci
npm run dev
```

1. ไปที่ **กล่องจัดเก็บ** เพื่อสร้างกล่อง ระบุห้องและตำแหน่ง และดาวน์โหลด QR Code สำหรับติดที่กล่อง
2. กด **เพิ่มสิ่งของ** เพื่อถ่ายรูปหรืออัปโหลดรูป เลือกกล่อง และบันทึกสภาพ วันที่ลงทะเบียน วันที่เริ่มเก็บ และวันเวลาหมดอายุ (ถ้ามี)
3. ค้นหาด้วยชื่อสิ่งของ รหัสกล่อง หรือสถานที่ หรือใช้ **สแกน QR กล่อง** จากกล้อง/ภาพ QR/รหัสกล่อง
4. ตั้งเตือนก่อนหมดอายุ **10 หรือ 15 นาที** ในแต่ละรายการ และเปิดการแจ้งเตือนบนอุปกรณ์ได้จาก **ตั้งค่า**

แอปมาพร้อมข้อมูลตัวอย่าง ข้อมูลและรูปบันทึกในเบราว์เซอร์ของเครื่องที่ใช้งาน ไม่ซิงก์ข้ามอุปกรณ์ หากล้างข้อมูลเว็บไซต์ รายการที่บันทึกจะหาย การเตือนต้องเปิดหน้าแอปไว้ และการแจ้งเตือนบนอุปกรณ์ต้องได้รับสิทธิ์จากเบราว์เซอร์ การใช้กล้องต้องเปิดผ่าน HTTPS หรือ localhost

```sh
npm test
npm run build
```
